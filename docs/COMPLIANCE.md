# Рекламні тексти та відповідність правилам

Принцип: привабливо = конкретно, зрозуміло, корисно. Не = обіцянки, страхи, «діагнози».
Жодна формула нижче не гарантує проходження модерації: перед кожним запуском звіряйте з актуальними політиками Google Ads / Meta та місцевим законом.

## Що перевірено (і наскільки надійно)
- **Google Ads:** політика Healthcare and medicines залежить від країни; заборонені речовини та «лікувальні» заяви (сторінки політик Google).
- **ЄС:** Регламент (ЄС) № 1924/2006 — заяви про здоров'я лише з дозволеного переліку; рішення Суду ЄС 2025 щодо ботанічних речовин у рекламі добавок (EUR-Lex, прес-реліз CJEU).
- **Таїланд:** Food Act, розділ 41 — попереднє погодження реклами користі; нова нотифікація про критерії реклами їжі (2026). Джерела: правові огляди (вторинні).
- **Індонезія:** регламенти BPOM 34/2022, 19/2022, 32/2022; UU PDP 27/2022. Джерела: тексти регламентів + вторинні.
- **Україна:** Закон «Про рекламу», ст. 21; закон 4122-IX. Джерела: новини та юридичні огляди (потрібна звірка на zakon.rada.gov.ua).
- **Казахстан:** реклама БАД відповідно до реєстрації; закон № 94-V. Вторинні джерела.
- **Решта країн зі списку:** НЕ перевірено (див. `src/config/geos.json`).

## Лексикон: замість → допустимо
| Не пишемо | Пишемо |
|---|---|
| «Лікує / усуває / знижує тиск» | «Склад і призначення за даними виробника» |
| «Гарантований результат / за 7 днів» | «Що вказано на етикетці і що кажуть джерела» |
| «Ви втомилися? У вас проблеми з…?» (особисті стани, Meta personal attributes) | «Як читати склад добавки», «Що перевірити перед вибором» |
| «Замінює ліки», порівняння з ліками | «Не є лікарським засобом» |
| «До/після», фото тіла | Фото упаковки та складу |
| «Лікарі радять», вигадані експерти й відгуки | Лише реальні перевірені дані з джерелами |
| «Залишилось 3 шт.», фальшиві таймери | Реальна ціна та дата перевірки |

## Допустимі формули привабливих заголовків
1. «[Назва]: склад, дозування і застереження — розбираємо по пунктах»
2. «Що на етикетці [категорія]: 5 пунктів, які варто перевірити перед вибором»
3. «Порівняння складу: [А] і [Б]» (лише за реальними даними)
4. «Як читати етикетку добавки: коротка інструкція»
5. «Огляд [назва]: що заявляє виробник і де це перевірити»
Усі без обіцянок результату й без звернення до особистого стану користувача.

## Обов'язкові елементи сторінки огляду
1. Розкриття комерційного зв'язку до першого CTA.
2. Дата перевірки ціни/умов і посилання на джерела.
3. Блок «Кому бути обережним».
4. ЄС: лише дозволені заяви про здоров'я (Reg. 1924/2006) або чітке позначення «заява виробника».
5. ГЕО з обов'язковою реєстрацією (UA, KZ, TH, ID тощо): номер або статус реєстрації продукту.
6. CTA-посилання з `rel="sponsored noopener"` і підписом «Партнерське посилання».

## Процес затвердження тексту для країни
1. Текст англійською + мовою країни →
2. перевірка за лексиконом →
3. звірка з політиками платформ і законом країни (`ad_copy_approved` у `geos.json`: false → true лише після перевірки) →
4. вичитка носієм мови →
5. публікація.
