# Useful Habit — аудит поточного стану (етап 1)

Дата: 1 листопада 2026. Перевірена збірка: `public/index.html` (один файл, ~540 КБ).

**Що запускалось:** автоматичний тест у jsdom (виконання JS без візуального рендеру): усі 28 мов, головна + політика + умови для кожної мови, напрямок RTL для AR/UR.
Результат: 0 помилок JS; 28/28 мов мають усі блоки, 18 карток і 9 пунктів «Важливої інформації»; обидва юридичні документи є в кожній мові.

**Чого НЕ перевірялось:** візуальний вигляд на реальних пристроях, швидкість (Lighthouse/CWV), реальний хостинг, GitHub (немає доступу до облікового запису).

## 1. Технології та архітектура
- Один статичний HTML-файл: CSS + JS + тексти 28 мов + логотип (base64) всередині.
- Маршрутизація: хеш (`#privacy`, `#terms`); мова зберігається в localStorage, URL не змінюється.
- Бекенду немає. Форма EnsoTraffic лежить окремо (`lead-form/`), на сайті не підключена.

## 2. Що зроблено добре
- Дизайн-система, адаптивність, іконки, світла палітра, прозорий логотип.
- 28 мов + RTL; юридичні тексти адаптовано під 28 мов (потребують вичитки).
- Жодних вигаданих відгуків, рейтингів, команди, статистики.
- Немає обіцянок результату; є застереження «не ліки».

## 3. Проблеми за пріоритетом

### CRITICAL
**C1. [ВИРІШЕНО варіантом A, 3 листопада 2026: `npm run build` генерує `/{lang}/`, `/{lang}/privacy/`, `/{lang}/terms/`, hreflang, canonical, sitemap.xml, robots.txt, 404; перевірено `scripts/verify-static.js`: 85 сторінок, 0 проблем] Немає окремих URL для мов і юридичних сторінок.**
Де: вся архітектура (хеш-маршрути, мова в localStorage).
Чому важливо: Google Ads і Meta перевіряють цільову сторінку та політику конфіденційності за реальним URL; пошукові системи не індексують `#privacy`; hreflang/canonical неможливі.
Виправлення: статична збірка `/{lang}/`, `/{lang}/privacy/`, `/{lang}/terms/` з hreflang і canonical (потрібне ваше погодження, див. ROADMAP).
Результат: індексація, коректна реклама по країнах.

**C2. Сайт обіцяє «огляди та порівняння», а жодного огляду немає.**
Де: hero («Інформація • Огляди • Продукти», «порівнюємо комплекси…»), блок «Огляди та статті».
Чому: розбіжність між заявленим і реальним вмістом = ризик Misrepresentation / Destination requirements (Google) і Landing Page Requirements (Meta); також «тонкий» контент.
Виправлення: опублікувати перші реальні огляди за шаблоном до запуску реклами або тимчасово змінити формулювання на те, що є.

**C3. Немає даних власника сайту.**
Де: футер, політики. Чому: GDPR вимагає ідентифікації контролера (та представника за ст. 27 для ЄС); платформи довіряють сайтам із прозорими контактами.
Виправлення: назва ФОП/ТОВ, адреса. Потрібні ваші дані (я їх не вигадую).

**C4. Немає cookie-згоди, а політика обіцяє «лише після згоди».**
Де: розділ про cookie в політиці; банера немає.
Чому: для ЄС обов'язково до підключення GA4/GTM/Meta Pixel; Google вимагає Consent Mode v2 для EEA.
Виправлення: банер із категоріями + блокування тегів до згоди.

### HIGH
- **H1.** Твердження в «Про нас» про процес («спираємося на офіційні джерела, датуємо матеріали») написані як наявний процес, хоча матеріалів ще немає. Переформулювати після публікації перших оглядів.
- **H2.** [ВИРІШЕНО: сторінка ~30–50 КБ замість 540 КБ] 540 КБ у кожному завантаженні: усі 28 мов + логотип 145 КБ base64 вантажаться кожному відвідувачу. Вплив на LCP/INP на мобільних. Виправлення: файли за мовами, логотип WebP/SVG.
- **H3.** Google Fonts блокують рендер і не мають повних fallback для TH/AR/UR/KA/HY. Виправлення: self-host, підмножини під мови.
- **H4.** Переклади 27 мов машинні, без вичитки носіями. Помилки в термінології здоров'я = ризик модерації.
- **H5.** Юридичні тексти не звірені з первинними джерелами для більшості ГЕО (див. `src/config/geos.json`, поле `verification`).
- **H6.** Немає аналітики й подій: GA4/GTM/Pixel/Ads згадані лише в політиці, коду немає (ID не надані, не вигадуємо).
- **H7.** Немає архітектури партнерських посилань: потрібні центральний реєстр оферів, розкриття, `rel="sponsored"`, передача UTM/click ID.

### MEDIUM
- **M1.** [ВИРІШЕНО: один H1 на сторінку] Два `<h1>` у DOM (головна + прихований юридичний вигляд). Лишити один видимий.
- **M2.** [ЧАСТКОВО: є og:image, robots, sitemap, robots.txt, canonical, hreflang; breadcrumbs — ні] Немає `og:image`, `robots`, `sitemap.xml`, `robots.txt`, `canonical`, `hreflang`, breadcrumbs.
- **M3.** Немає Contact, Cookie Policy, Affiliate Disclosure, Medical Disclaimer як окремих URL (частково є в «Важливій інформації» та Умовах).
- **M4.** Фоновий декор (48 анімованих SVG): перевірити вплив на CLS/INP на слабких пристроях; `prefers-reduced-motion` уже враховано.
- **M5.** [ВИРІШЕНО: усі посилання ведуть на реальні URL] Посилання на політику з форми (`#privacy`) після переходу на статичні URL потрібно замінити.

### LOW
- **L1.** [ВИРІШЕНО: фавікон із логотипу] Фавікон лише emoji. **L2.** [ВИРІШЕНО: 404.html] Немає сторінки 404.

## 4. Рекламна готовність (Google / Meta)
Не готово до запуску через C1–C4. Тексти оголошень мають відповідати реальному вмісту сторінок; кожне ГЕО потребує окремої перевірки правил (див. COMPLIANCE.md). Проходження модерації не гарантується.
